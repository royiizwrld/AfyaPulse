# AfyaPulse
"Digital Tools, Healthy mothers, Thriving children."
AfyaPulse gives clinic staff a digital version of the MOH 405 and MOH 710 registers, with the same columns, the same codes and the summary tables worked out automatically.

AfyaPulse is a full-stack Progressive Web App (PWA) designed to digitize critical clinical documentation—specifically replacing traditional MOH 405 and MOH 710 registers with automated, real-time data entry and reporting workflows.

Frontend & Architecture: Built with modern web standards and packaged as a Progressive Web App (PWA) to ensure seamless offline-first capability for clinic staff working in low-connectivity environments. Styled for high usability and deployed globally via Netlify for lightning-fast content delivery.

Database & Backend Services: Powered by Supabase (PostgreSQL) to handle secure relational data storage, real-time database synchronization, and scalable backend queries.

Authentication & Security: Integrated with Brevo APIs to manage secure user verification, automated email confirmation workflows, and role-based access control.

AI & Intelligence Layer: Leverages Google AI Studio (Gemini) embedded directly within the app as an intelligent assistant to help clinicians query data insights, streamline entries, and reduce administrative bottlenecks.
